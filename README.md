# Sorry, Lavi 💌
React + Vite apology site.

1. Install Node.js (v18+) from nodejs.org
2. In this folder run: `npm install` then `npm run dev`
3. Open the link it shows. Edit names/links at the top of `src/App.jsx`.
4. To put it online (free): `npm run build`, then upload the `dist` folder to Netlify Drop or Vercel.
